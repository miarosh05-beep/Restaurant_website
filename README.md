# Restaurant_website

A restaurant website with an admin panel that lets the owner update the site content in real time, no code needed.

##  What's inside
- Public website - plain HTML/CSS/JS, no framework
- Admin panel + API - Node.js running as Vercel Serverless Functions
- Database -Redis (Upstash) for storing content (menu, text, etc.)
- Image storage - Vercel Blob
- Hosting - everything runs on Vercel

## The problem it solves
Most restaurant owners can't easily update their menu or site content without asking a developer. This project gives them full control through a simple admin panel - no coding required.

## Tech stack
`HTML` `CSS` `JavaScript` `Node.js` `Vercel Serverless Functions` `Redis (Upstash)` `Vercel Blob`
